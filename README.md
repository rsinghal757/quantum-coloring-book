# The Quantum Computing Coloring Book - Online Edition

An interactive web version of [The Quantum Computing Coloring Book](https://wonders.physics.wisc.edu/quantum/quantum-computing-coloring-book/), originally created by Aedan Gardill and Sarah Parker.

Built with ❤️ by [Rohit Singhal](https://github.com/rohitsinghal).

## 🎨 About the Project

This project brings the educational and artistic world of quantum computing to the web. It allows users to read about fundamental quantum concepts and "color" the illustrations digitally.

The content covers topics such as:
- Origins of Quantum Computing
- Entanglement & Superposition
- Qubits (Superconducting, Neutral Atom, Trapped Ion, etc.)
- Leading Scientists in the field

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rohitsinghal/quantum-coloring-book.git
   cd quantum-coloring-book
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:5173`

## 🛠️ Tech Stack

- **React**: UI Library
- **Vite**: Build tool and dev server
- **HTML5 Canvas**: For the interactive coloring functionality
